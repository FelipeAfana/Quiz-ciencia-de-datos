Lector de Placas Vehiculares con YOLOv8, EasyOCR y Expo

Aplicación móvil para la detección y reconocimiento automático de placas vehiculares utilizando visión por computadora, inteligencia artificial y procesamiento OCR.

La solución está compuesta por:

Frontend móvil desarrollado con Expo y React Native.
Backend desarrollado con FastAPI.
Modelo YOLOv8 para detección de placas.
EasyOCR para reconocimiento de caracteres.
Despliegue del backend en AWS EC2.
Descripción

Este proyecto permite capturar una imagen desde la cámara de un dispositivo móvil, enviarla a un servidor de inferencia y obtener automáticamente la placa detectada.

El sistema identifica la ubicación de la placa mediante YOLOv8 y posteriormente utiliza EasyOCR para extraer los caracteres alfanuméricos
